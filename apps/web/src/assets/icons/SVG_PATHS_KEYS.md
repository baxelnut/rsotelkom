## Notes

- No `burger` key, use `list` for hamburger menu icon
- No `dashboard` key, use `grid` or `houseDoor`
- No `feed` key, use `list` or `globe`
- No `earnings` key, use `currencyDollar` or `barChart`
- No `subscribers` key, use `people`
- No `post` key, use `pencilSquare` or `fileEarmarkText`
- No `site` key, use `globe` or `window`
